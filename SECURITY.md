# Reporting security vulnerabilities

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/changeclause/examples/security/advisories/new), or email [dev@changeclause.com](mailto:dev@changeclause.com) if that route is unavailable. Include the affected commit and a minimal sanitized reproduction; exclude secrets, customer data, and private code.

The authentication-boundary violation is intentional synthetic behavior, not itself a security finding. Use [ordinary issues](https://github.com/changeclause/examples/issues) for unclear results or reproduction problems. For a vulnerability in the verifier itself, use the [tool's reporting guidance](https://github.com/changeclause/changeclause/blob/main/SECURITY.md).
